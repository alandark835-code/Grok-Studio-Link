## Qué es esta RC

Cierra el ciclo Beta con herramientas de **calidad y operación** que aportan valor aunque no tengas API ni MCP:

| Área | Qué hace de verdad |
|------|--------------------|
| Debugger | Análisis estático Luau (remotos, wait, loadstring, etc.) |
| Playtest | Checklist manual + `PLAYTEST_REPORT.md` (sin fingir automatización) |
| Performance | Hints estáticos de lag/patrones costosos |
| Backups | Listar / crear / restaurar con seguridad |
| Settings | Rutas + health check de dependencias |
| ZIP / Builder / Export / Rojo / MCP / Providers | Lo de Beta |

## Principio de honestidad

- No se marca playtest como pasado sin tu checklist.
- Debugger y Performance **no** son el analizador oficial de Roblox.
- MCP y API son opcionales; FREE MODE funciona sin ellos.
